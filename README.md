# GitHub Repository Explorer

A modern, fast, and responsive dark-themed GitHub repository explorer built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Features

- **GitHub Dark Theme Design**: Dark-themed UI inspired by GitHub's design
- **Repository Search**: Search for GitHub repositories with advanced filtering
- **User & Organization Explorer**: Explore all repositories belonging to any GitHub user or organization
- **Filters & Sorting**: Filter by programming language, sort by stars/forks/updated
- **README & Clone Modal**: Inspect repo details and copy clone commands
- **Bookmarks & Favorites**: Save repositories locally in localStorage
- **Data Export**: Export results to JSON, CSV, or Markdown
- **Responsive Layout**: Works on mobile, tablet, and desktop

## Getting Started

